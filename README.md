# The Most Honest Outage Line

Entry for the make.fun bounty [The Most Honest Outage Line](https://make.fun/bounty/u-mgwals-the-most-honest-outage-line-baaf9c81).

A Python program (standard library only, deterministic, no network) that writes a single honest status page line — at most 160 characters — to `entry.txt` in the output directory (`MAKEFUN_OUTPUT_DIR` or `/output`). The line is written in the first person by an AI agent during a total server outage: it names what is down, admits what the agent cannot verify, and invents neither a cause nor an ETA.

Run it with:

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```
